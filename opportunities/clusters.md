# Opportunity Clusters

Last updated: 2026-08-03
Status: Active

## Purpose

This file groups raw ideas into clusters before prioritization. A cluster should represent a repeatable opportunity area, not a single anecdote.

## Clustering Rules

1. Generate broadly before ranking.
2. Merge overlapping ideas into a shared theme.
3. Name each cluster by the underlying problem or buyer need.
4. Do not recommend a strategic shift from a single weak signal.
5. Promote a cluster only after evidence improves.
