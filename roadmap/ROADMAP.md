# Roadmap

Last updated: 2026-08-04
Status: Active

## Current Phase

Atlas is moving from exploration to exploitation.

The immediate phase is to lock the source-of-truth operating documents, finalize the primitive vocabulary, and prepare the first disciplined clustering pass. The goal is not to cluster all 700 ideas at once. The goal is to build the taxonomy the ideas will fit into.

## Current Priorities

1. Establish durable operating documents and the Atlas constitution.
2. Confirm the first primitive set and definitions.
3. Prepare the Top 50 ideas for the first clustering exercise.

## Next Milestones

1. Sanity-check the primitive taxonomy against the strongest ideas.
2. Assign the Top 50 ideas to primitives and note mismatches.
3. Merge primitives into larger strategic themes or opportunity families.
4. Create one-page memos for the strongest clusters.
5. Score clusters, not isolated ideas.
6. Research the top-ranked clusters before committing to MVP work.

## Upcoming Clustering Work

Clustering should follow these rules:

1. Cluster by underlying value engine, job, or primitive rather than by industry.
2. Use the primitive test: if the primitive disappeared, would the idea still exist?
3. Keep beachhead, wedge, and evidence gaps visible for every cluster.
4. Treat a cluster as stronger than any single flashy idea.
5. Revise the taxonomy before scaling if the Top 50 do not fit cleanly.

## Major Decisions Already Made

1. The repository is the source of truth.
2. Broad generation precedes prioritization.
3. Recommendations should be concise and best-answer-first.
4. Evidence is required before strategy changes.

## Inputs Needed For The Next Phase

1. A canonical Top 50 list from the broader idea inventory.
2. A stable primitive list with draft definitions.
3. A lightweight scoring rubric for cluster comparison.
