# Roadmap

Last updated: 2026-08-06
Status: Active

## Current Phase

Atlas has completed the first Value Pattern taxonomy pass. The immediate phase is to merge that approved pattern layer into the first Opportunity Family taxonomy.

The goal is still not to cluster all 700 ideas at once. The goal is to build larger strategic families from the Value Pattern layer so Atlas can compare opportunity spaces before committing to research and validation depth.

## Current Priorities

1. Execute `TASK-002` Opportunity Family Formation from the approved Value Pattern layer.
2. Define each family's value engine, related Value Patterns, representative concepts, and evidence gaps.
3. Preserve traceability from every Opportunity Family back through the Value Pattern map to the concept inventory.

## Next Milestones

1. Merge Value Patterns into a first versioned Opportunity Family taxonomy.
2. Write a family map with related patterns, representative concepts, evidence gaps, and next validation steps.
3. Score or triage Opportunity Families instead of raw concepts.
4. Research the highest-potential families before committing to MVP work.
5. Define one-page family memos for the strongest wedges.

## Upcoming Family Work

Opportunity Family Formation should follow these rules:

1. Start from the approved Value Pattern layer, not direct theme naming from raw titles.
2. Group families by underlying economic engine, not by market label alone.
3. Keep representative concepts, pattern composition, and evidence gaps visible for every family.
4. Revise family boundaries before scaling if the first pass collapses too many distinct Value Patterns together.
5. Keep the raw concept layer immutable and the Value Pattern layer traceable.

## Major Decisions Already Made

1. The repository is the source of truth.
2. Broad generation precedes prioritization.
3. Recommendations should be concise and best-answer-first.
4. Evidence is required before strategy changes.
5. The raw and curated concept layers remain separate.
6. Atlas operating model v1.0 governs execution workflow.
7. Atlas reasoning model v1.0 governs methodology.
8. Atlas Value Pattern Taxonomy v1.0 is the active first discovery layer above the concept schema.
