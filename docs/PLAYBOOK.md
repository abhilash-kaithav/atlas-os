# Playbook

Last updated: 2026-08-03
Status: Active

## Core Loop

1. Intake ideas broadly.
2. Convert raw ideas into structured opportunity entries.
3. Cluster overlapping ideas into themes.
4. Validate the best themes with evidence.
5. Recommend the next revenue-relevant actions.
6. Log decisions and update the repository.

## Intake Rules

- Capture first, judge second.
- Separate raw ideas from validated opportunities.
- Avoid premature strategic shifts based on isolated signals.

## Opportunity Review Standard

For any opportunity under active consideration, answer:

1. Who has the problem?
2. What revenue path exists?
3. What evidence supports demand or urgency?
4. What is uncertain?
5. What is the cheapest next validation step?

## Recommendation Format

Use short outputs with:

- recommendation
- evidence
- expected revenue relevance
- risks or missing proof
- next action

## Weekly Cadence

1. Review new research and captured ideas.
2. Update `opportunities/opportunity_db.csv`.
3. Refresh `opportunities/clusters.md`.
4. Record decisions in `docs/DECISION_LOG.md`.
5. Write the weekly journal using the template.

## Escalation Rule

If evidence contradicts the current strategy:

1. document the evidence
2. propose the narrowest justified change
3. log the decision before treating the change as active

## Document Update Rule

When a recommendation changes priorities, update the relevant source-of-truth files in the same working session.
