# Product Boundary

Last updated: 2026-08-05
Status: Active

## Mission Boundary

### What Atlas Solves

- Discovering high-leverage venture opportunities before they are obvious.
- Turning ideas, research, and signals into a structured opportunity intelligence system.
- Helping determine which venture opportunities deserve validation, focus, and eventual building.

### What Atlas Explicitly Does Not Solve

- Teaching founders how to execute a startup after the opportunity is already chosen.
- Operating as a startup accelerator, course platform, mentor network, or playbook library.
- Optimizing fundraising, team management, or generic startup execution workflows.

## Product Boundary

| Atlas Is | Atlas Is Not |
| --- | --- |
| Opportunity discovery engine | Startup accelerator |
| Knowledge graph | Course platform |
| Intelligence system | Idea database |
| AI-native reasoning platform | Prompt library |
| Venture discovery workflow | Startup execution workflow |

## Competitive Boundary

### StartupScience

- StartupScience optimizes startup execution.
- Atlas optimizes opportunity discovery.
- Overlap: founders.
- Key distinction: Atlas begins before the startup exists.

## Strategic Tests

1. Does this improve opportunity discovery?
2. Does this strengthen the knowledge graph?
3. Does this create a compounding moat?
4. Could a startup education company build this as a feature?

If the answer to question four is yes, pause and evaluate carefully. If the answer is no, Atlas is more likely operating inside its true boundary.

## Product Thesis

Atlas is building the world's opportunity intelligence system.

Its purpose is to discover high-leverage venture opportunities that should exist, not to help founders execute ideas that already exist.
